# Arduino Ultrasonic Radar Scanner

A radar-style scanner built using:
- Arduino Mega
- Ultrasonic sensor
- Servo motor
- Processing visualization

## Features
- Real-time distance detection
- Servo sweep scanning
- Radar visualization on PC

## Components
- Arduino Mega 2560
- HC-SR04
- SG90 Servo

## Wiring
TRIG -> Pin 9
ECHO -> Pin 10
SERVO -> Pin 6
